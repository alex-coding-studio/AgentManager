# Output risks: Just Do It

- Plan looks plausible but ignores a user's exclusion: requires live planning
  evaluation; semantic schema validation cannot establish intent fidelity.
- Steps become technical file inventories: prompts request observable outcomes
  and semantic inputs; fixed website case illustrates this, not a proven model effect.
- Agent labels an input as delivery: reject without current-round host observation.
- Review accepts the wrong version or treats a suggestion as a blocker: bind
  output identity and separate findings/advisories; model judgment remains open.
- Summary loses a user correction or invents acceptance: preserve original input
  in references, keep host events separate and mark summary coverage.
- Context silently grows into full transcripts: cap the main handoff's recent
  links, retain a separate index and use on-demand references. Storage scalability
  and long-running live comprehension are not yet evaluated.
- Installed Skill starts autonomous delivery: module-method policy cannot expand
  host authority; actual runtime Skill loading and conflict enforcement are pending.

Risk checks and the unverified behavior boundary are summarized in
[the scorecard](output_quality_scorecard.md).
